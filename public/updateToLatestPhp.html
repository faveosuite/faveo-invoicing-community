PHP 8.4 Upgrade Required

Your Faveo Invoicing installation requires PHP 8.4 or higher

Why Upgrade?

Your server is currently running an outdated PHP version. For security, stability, and optimal performance, Faveo Invoicing now supports PHP 8.4 and above only.

  • ⚡ Improved system performance
  • 🔐 Enhanced security patches
  • 🚀 Better compatibility & stability
  • 📈 Long-term support
Next Steps

Update your server to PHP 8.4 and install the latest Ioncube Loader.

Important:
After upgrading PHP and Ioncube, remove updateToLatestPhp.html from your root directory. Then proceed with the database upgrade process.
